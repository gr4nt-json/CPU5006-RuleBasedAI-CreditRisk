"# CPU5006: Rule-Based AI Credit Risk Assessment" 
"" 
"## Overview" 
"This repository contains the Python implementation and experimental data for the CPU5006 Assessment 1 Scientific Paper. It compares a Deterministic Knockout Expert System against a Weighted Scoring Rule Engine for predicting consumer credit risk." 
"" 
"## Files Included" 
"- \`main.py\`: Core algorithm implementation and metric evaluation." 
"- \`visualise.py\`: Script generating academic confusion matrices and performance charts." 
"- \`credit_risk.csv\`: The dataset used for empirical evaluation." 
"- \`experiment_results.csv\`: Raw output metrics from the experimental execution."
